# SFSC2026: first-model evidence and selection

Research date: 2026-09-05. This is a design recommendation, not a benchmark result. No candidate has measured SFSC validation PQ, runtime, or peak memory in this report.

## Objective and constraints

The current official overview confirms **Panoptic Quality**, with separate attention to fragmentation, merging, morphology, and computational efficiency. Its evaluation section allows external data but forbids other ground-truth metadata for training; inference uses only the supplied H-alpha images. The formal rules page did not expose readable content through the browser. The first run should therefore use only supplied images and segmentation masks, randomly initialized weights, and no supplied spines, categories, or boxes. Geometry derived from the masks is a proposed target-construction choice, not additional annotated supervision. ## Six candidates in three research lanes

| Lane / candidate | Primary evidence | Proposed SFSC adaptation and expected tradeoff | Decision |
|---|---|---|---|
| A1 — residual U-Net foreground baseline | U-Net combines context and localization with augmentation for limited annotated data. Residual U-Net was studied for road masks. [U-Net](https://arxiv.org/abs/1505.04597), [Residual U-Net](https://arxiv.org/abs/1711.10684) | Native grayscale crops; foreground logits; weighted BCE plus Dice; global connected components. Relatively small implementation and head cost. Touching filaments can merge. | Keep as inexpensive ablation using the selected model's foreground output. |
| A2 — contour-aware residual U-Net | DCAN jointly predicts object regions and contours to separate clustered instances. [DCAN](https://arxiv.org/abs/1604.02677) | Foreground plus narrow mask-derived boundary and interior/seed channels; globally stitched probabilities then seeded watershed. Flexible masks avoid a prescribed geometric shape. Extra output channels are cheap relative to the encoder; boundary erosion can erase the thinnest branches. | **Selected first training architecture.** |
| B1 — topology-aware residual U-Net | soft-clDice trains using differentiable skeleton-based overlap and was evaluated on tubular structures. [clDice](https://openaccess.thecvf.com/content/CVPR2021/html/Shit_clDice_-_A_Novel_Topology-Preserving_Loss_Function_for_Tubular_Structure_CVPR_2021_paper.html) | Add low-weight mask-derived soft-clDice to A2 after a stable reference run. Potentially preserves continuity; connectivity loss alone does not distinguish neighboring instances and can favor false bridges. Adds iterative pooling and tuning cost. | Next loss ablation, especially if false splits dominate. |
| B2 — HoVer-style offsets and watershed | HoVer-Net predicts horizontal/vertical distances to instance centers to separate nuclei. [HoVer-Net](https://arxiv.org/abs/1812.06499) | Replace nuclei-specific classification with a foreground head and mask-derived offsets. Stronger separation signal but filament centroids can lie outside curved objects, and cropped long objects create target discontinuities. More target/postprocessing complexity. | Reserve for evidence of touching-instance failure. |
| C1 — StarDist-style polygon instances | StarDist predicts star-convex polygons per pixel with instance selection. [StarDist](https://arxiv.org/abs/1806.03535) | Natural direct instances and a manageable dense backbone, but bent, branched filaments need not be star-convex. More rays cannot remove the star-convexity restriction. Domain mismatch is an inference from geometry, not a measured failure on this dataset. | Deprioritize for the first run. |
| C2 — Mask R-CNN instances | Mask R-CNN adds an instance-mask branch to proposal-based detection. [Mask R-CNN](https://arxiv.org/abs/1703.06870) | Explicit independent instances could avoid some semantic merges, but long thin objects need careful feature stride, anchors, mask resolution, and tile fusion. Highest engineering burden under zero-install TensorFlow/P100 and random initialization. | Defer until dense-model PQ establishes a reference. |

These lanes are alternatives for comparison, not six concurrent GPU jobs. Papers demonstrate capabilities on their own datasets; they do not establish that one candidate will win SFSC2026.

## Selected first run

Implement a compact residual U-Net, with a single grayscale input, four reductions in resolution, skip connections, and full-resolution foreground/boundary/interior logits. A starting width of 24 or 32 and 768-pixel native crops is an engineering proposal; log parameter count, run a real gradient step, and lower batch size before reducing spatial resolution if memory is exceeded. Avoid a pretrained encoder in this run. The U-Net and residual papers motivate the backbone; this exact architecture and head combination is an adaptation rather than a reproduction. [U-Net](https://arxiv.org/abs/1505.04597), [Residual U-Net](https://arxiv.org/abs/1711.10684), [DCAN](https://arxiv.org/abs/1604.02677).

Use one complete annotation set per sampled image, then sample native crops with both foreground-centered and unconstrained/background examples. Derive the sampling locations, contours, and interior targets from permitted masks. Apply matching flips/right-angle rotations to inputs and targets, plus modest photometric perturbations. Do not use severe resize augmentation that erases valid thin structures. Loss: weighted BCE plus Dice on foreground, with smaller auxiliary boundary/interior contributions. Ensure empty-foreground crops yield finite meaningful losses. These exact weights and sampling rates require validation; no paper fixes them for this competition.

The broader lesson from nnU-Net is to configure preprocessing, architecture, training, and postprocessing together according to dataset characteristics. Adopt that principle, not an unverified claim to run the nnU-Net package. [nnU-Net paper](https://arxiv.org/abs/1904.08128).

Infer overlapping native-resolution tiles and blend each probability channel into a complete 2048×2048 map **before** extracting instances. Test foreground-only connected components alongside watershed from learned interior seeds. Add one fallback seed to any foreground component with no surviving seed; use thin boundary targets and small/no seed erosion to avoid losing narrow filaments. Avoid unrestricted local-maxima seeds, which can fragment a single elongated filament. Do not impose a blanket minimum size of 256 pixels because the local audit contains valid smaller objects. These are geometry-driven engineering safeguards, to be selected by validation PQ.

Save checkpoints during training, score full-frame validation predictions using the existing fixed evaluation contract, and select foreground/seed/boundary/minimum-size thresholds using validation only. Log both aggregate counts and per-record scores so any official aggregation discrepancy can be audited. Never select by crop Dice alone. The published PQ definition captures recognition and mask overlap, and therefore does not allow a strong semantic overlap score to excuse false instances. [Panoptic Segmentation](https://arxiv.org/abs/1801.00868), [local evaluation contract](/Users/hariohm/dev/au-personal/SFSC2026/EVAL.md).

## Risks and evidence required before claiming model quality

- Thin interior targets can vanish; verify target construction on the smallest and narrowest real masks and keep foreground reconstruction independent of seed width.
- Some long objects exceed a crop. Full-frame stitching avoids tile-wise duplicate instances but cannot restore missing context learned during training. Inspect the longest filaments and consider larger crops only after measured memory fit.
- Multiple labels for the same image can disagree. Separate annotator targets and filename grouping prevent duplicate-target unions and leakage but do not remove annotation noise.
- Oversampling foreground changes foreground prevalence. Retain negative crops and tune detection thresholds on complete validation frames.
- Measure actual GPU identity, peak memory, training throughput, validation PQ, false splits, and false merges. No quality or GPU-hour estimate is asserted here.
